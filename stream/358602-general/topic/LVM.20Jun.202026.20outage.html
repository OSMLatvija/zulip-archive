kaposts (Aug 12 2026 at 19:02):

For the elevation map I just recently tried using the data from here https://www.lgia.gov.lv/lv/Digit%C4%81lais%20virsmas%20modelis

The process isn't as convenient as getting WMS tiles in JOSM/id and it's not a replacement but it also has some advantages and allows things you couldn't do with fixed prerendered tiles:

  • you get actual point cloud with categorized points and elevation values
  • can toggle presence of high/medium vegetation to better see what's under the trees (classification isn't perfect but it's better than nothing)
  • choose how exactly the data is rendered based on classification, hillshade, height based color gradient or something else

The workflow is more or less like this:

  • Enable topographic map background so that you can more easily find the region you need
  • download the .las file
  • open the .las file in QGIS
  • set a suitable CRS, EPSG:10306 and EPSG:3059 seemed to work
  • customize display options or open the 3d view
Digitālā augstuma modeļa pamatdati
